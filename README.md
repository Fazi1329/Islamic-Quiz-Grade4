# Surah Al-Fatiha: Meaning Challenge 📖✨

An interactive, Islamic-inspired educational quiz application designed for students to learn, memorize, and understand the complete English meaning of all **7 verses of Surah Al-Fatiha** one verse at a time.

![Surah Al-Fatiha Quiz](background.jpg)

## 🌟 Features

- **Sequential Progression**: Verses are unlocked one by one from Verse 1 to Verse 7.
- **Intelligent Meaning Evaluator**:
  - Automatically assesses the student's typed response against reference translations.
  - Case-insensitive, tolerant of punctuation, spacing, and minor spelling typos.
  - Preserves essential semantic meaning rather than strict rigid matching.
  - **Verse 7 Strict Clause Check**: Ensures all 3 essential components are present:
    1. *The path of those blessed / favored*
    2. *Not those who have earned anger / wrath*
    3. *Nor those who have gone astray*
- **Aesthetic Islamic Design**:
  - Emerald green (`#064e3b`), ivory, and gold accents.
  - Beautiful Arabic typography (`Amiri` font) with full tashkeel and transliteration.
  - Animated progress bar and completed verses counter.
- **Full-Screen Celebration & Confetti**:
  - MashaAllah congratulatory screen upon reaching 7/7 (100%).
  - Canvas confetti particle animation.
- **Answer Review Screen**:
  - Displays student's typed meaning side-by-side with approved reference meanings for all 7 verses.
- **Teacher Customization Mode**:
  - Edit or add approved alternative translations.
  - Toggle hint display after 3 attempts.
  - Adjust grading strictness.
- **Audio Recitation & Sound Effects**:
  - Audio recitation for each verse.
  - Synthesized Web Audio API sound effects (100% offline, with mute toggle).
- **Responsive**: Works on desktop, tablets, and mobile devices.

## 🚀 Live Demo / GitHub Pages

To host this repository on GitHub Pages:
1. Go to your repository **Settings** on GitHub.
2. Under **Code and automation**, click **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your quiz will be live on the web!

## 💻 Local Usage

Simply clone or download this repository and open `index.html` in any web browser:
```bash
git clone https://github.com/Fazi1329/Islamic-Quiz-Grade4.git
cd Islamic-Quiz-Grade4
```
Double-click `index.html` or start a local server:
```bash
npx serve .
# or
python -m http.server 3000
```
